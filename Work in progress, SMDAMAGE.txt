- Design note: rotation assignment must precede the carbon calculations
When a pixel’s Faustmann-optimal rotation T* is shorter than the assigned contract length T_assigned
(e.g., T*=3 but the bucket floor is 30), the carbon schedule and the bid price must reflect T_assigned for the database:

1. Carbon schedule. The year-by-year tC_per_ha_per_year profile is determined by g_harvestyear
   inside the plantation year loops in process_country(). If load_harvest_year_buckets() sets
   T*=3 to T_assigned=30 before those loops run, the modulo harvest arithmetic uses 30, so the
   carbon profile reflects 30 years of uninterrupted forest growth — not cyclic 3-year clear-cuts.
   That is the carbon schedule in SMDAMAGE for a 30-year contract.

2. Bid price. write_single_rate_npv_to_table() computes:
     bid = establishment_cost + crop_va × annuity(T_assigned) − wood_revenue(T_assigned)
   At T_assigned > T*, the landowner foregoes more agricultural income (longer annuity) and receives
   wood revenue later and less frequently. The bid is therefore higher than at T*, which is
   economically correct: offering a sub-optimal rotation requires more compensation.

Mechanism: load_harvest_year_buckets() in `1_import_Busch2024_to_SMDAMAGE.py` builds a dict
{original_year: chosen_year} from the CSV, then pre-fills every year below the CSV minimum with
min(chosen_years). Since calculate_harvest_year() applies this dict to the raw Faustmann series,
all pixels receive a bucket representative before process_country() runs its carbon year loops.

How 1_import_Busch2024_to_SMDAMAGE.py works

Example algebraic description: natural regeneration for one explicit case

Choose one pixel with these inputs after the screen filters:
- country in the Americas, fao_ecoz = 12, so the code uses nr_rootshoot = 0.2845.
- nr_A = 80
- nr_k = 0.03
- crop_va = 50 USD/ha/year
- nr_cost in the raw Busch data = 500 USD/ha in 2011 dollars
- time horizon T = 120 years

Step 1. Convert natural-regeneration cost to 2020 dollars.
The code multiplies nr_cost by 1.1577: nr_cost_2020 = 500 x 1.1577 = 578.85 USD/ha

Step 2. Pick the natural-regeneration root:shoot ratio.
For this explicit branch, fao_ecoz = 12 and continent = AMER, so the code uses the lookup nr_rootshoot = 0.2845.

Step 3. Compute cumulative natural-regeneration carbon at year t.
In the code, natural-regeneration cumulative carbon per hectare is
C_nr(t) = (AGB_C_POOL + BGB_C_POOL x nr_rootshoot) x nr_A x (1 - e^(-nr_k t))^2
          + SOIL_C_POOL x t x (NATURAL_SOIL_C + PLANTATION_SOIL_C)

Here all carbon-pool switches are 1, so this becomes
C_nr(t) = (1 + 0.2845) x 80 x (1 - e^(-0.03 t))^2 + t x (0.415107735 + 0.092749069)
	 = 102.76 x (1 - e^(-0.03 t))^2 + 0.507856804 x t

Interpretation:
- the first term is aboveground plus belowground biomass from the Chapman-Richards curve
- the second term is the soil-carbon term added linearly each year in this implementation

Step 4. Compute total natural-regeneration carbon at the 120-year horizon.

At t = 120, (1 - e^(-0.03 x 120))^2 = (1 - e^(-3.6))^2 about 0.946099
so biomass carbon is 102.76 x 0.946099 about 97.2211 tC/ha
and soil carbon is 0.507856804 x 120 about 60.9428 tC/ha

Therefore C_nr(120) about 97.2211 + 60.9428 = 158.1640 tC/ha
This is the code variable nr_wohrv_total_tC_per_ha for this pixel.

Step 5. Convert cumulative carbon into annual removals for export.
The database table tC_per_h_per_year stores annual increments, not the cumulative stock.
So the code computes
annual_nr(1) = C_nr(1)
annual_nr(t) = C_nr(t) - C_nr(t - 1) for t >= 2

For this example,
annual_nr(1) about 0.5976 tC/ha/year
annual_nr(2) about 0.7666 tC/ha/year
and so on through year 120.

Step 6. Compute natural-regeneration cost-effectiveness.
The code calculates
	nr_costeff = (crop_va x T + nr_cost_2020) / (3.67 x C_nr(T))
		= (50 x 120 + 578.85) / (3.67 x 158.1640) = 6578.85 / 580.4619, about 11.33 USD/tCO2

This is the code variable nr_wohrv_costeff_USD_per_tCO2.

Step 7. If natural regeneration beats plantation, export fields are written as follows.
If the plantation comparison implies refortype_whrv_tCO2_per_USD = "N", the output row uses
- selected_option = natural_regeneration
- selected_A = nr_A = 80
- selected_k = nr_k = 0.03
- selected_rotation_year = 120
- selected_establishment_cost_USD_per_ha = nr_cost_2020 = 578.85
- p_USD_per_tC_harvested = 0

Important note: the code does compute nr_harvestyear from the Faustmann rule, but for a natural-regeneration winner it does not export that year as selected_rotation_year. The export writes the full time horizon, 120, for natural regeneration.
