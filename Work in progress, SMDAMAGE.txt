Updating reduced cost calculation for forestry land constraint
======================================================================

Section 5.2 of Solve_SMDAMAGE (lines ~257-271) tests whether a new forestry bid step should enter the restricted LP using:
    next_reduced_cost = next_coeff * discount / kt_divisor + Vpt(tree,t).pi.

For non-forestry removers (Agriculture, Seaweed) this is correct: the  Vpt dual should capture only the temperature-constraint shadow price.
For forestry bidders, vpt[tree, t] also appears in one Forestry_Land_{t'} constraint for EVERY period t' in [t, t + rotation(tree) - 1].
The land constraint's shadow price therefore affects π_Vpt[tree,t] via the LP KKT conditions.

ALGEBRAIC DERIVATION

Variables for forestry bidder tree, planting period t:
    qapt[a,tree,t]  ∈ [0, Uapt]      (mhectares at bid step a)
    vpt[tree,t]     free              (total mhectares planted)

Constraints where qapt[a,tree,t] appears directly:
    (A) Vpt(tree,t): vpt[tree,t] - Σ_a qapt[a,tree,t] = 0, dual: π_{tree,t}  (any sign)

    qapt has coefficient -1 in (A) and zero in every other constraint.

LOOKS WRONG
LP reduced cost of qapt[a,tree,t] at lower bound 0: rc = inflate * Bapt[a,tree,t]  +  π_{tree,t}           ...(1)

	or sum [u in range(t, t + rotation(tree)] π_{tree,u}           ...(1)???

Entry condition:  rc > 0.

Constraints where vpt[tree,t] appears (free variable):
    (A) Vpt(tree,t): coeff +1,  dual π_{tree,t}.
    (B) TaxedTemp_t(s) for all s ≥ t: coeff Wpt[tree, s-t], dual ω_s (or Temp_t(s) in non-revenue-neutral case)
    (C) Forestry_Land_{t'} for all t' ∈ [t, t + rot(tree) - 1]: coeff +1,  dual λ_{t'} ≥ 0

KKT stationarity for the free variable vpt[tree,t] (c = 0):
    0 = π_{tree,t} · 1  + Σ_{s ≥ t, s∈ConstraintPeriods} ω_s · Wpt[tree, s-t]  + Σ_{t'=t}^{t+rot(tree)-1} λ_{t'}

From KKT on taxedTempChange[s] (free): ω_s = σ_s = Capt(s).pi ≥ 0.
Wpt[tree,s-t] < 0 for a remover (sequestration cools the climate).

Solving for π_{tree,t}: π_{tree,t} = - Σ_{s≥t} ω_s · Wpt[tree,s-t] - Σ_{t'=t}^{t+rot-1} λ_{t'}  =  cooling_value(tree,t) - land_rent(tree,t)

where:
    cooling_value = Σ_{s∈ConstraintPeriods,s≥t} Capt(s).pi * (-Wpt[tree,s-t])   ≥ 0
    land_rent     = Σ_{t'=t}^{t+rot(tree)-1} Forestry_Land_{t'}.pi            ≥ 0

Substituting into (1): rc(a,tree,t) = inflate · Bapt[a,tree,t] + cooling_value(tree,t) - land_rent(tree,t)   (★)

Economics: the discounted bid cost plus the cooling benefit must EXCEED the land rent for a forestry column to enter the LP.

The current code uses dual_pi[(tree,t)] = π_{tree,t} which by the KKT identity equals (cooling_value - land_rent).
The two formulas are algebraically equivalent in a non-degenerate LP.  The explicit form (★) is preferred
because it remains correct when the LP solver returns π_Vpt = 0 due to degeneracy.

REPLACEMENT CODE (section 5.2 of Solve_SMDAMAGE)
-------------------------------------------------
Replace the block that begins "for (p, t) in PT_set:" with:

    # 5.2. Decide whether to add the next bid steps.
    for (p, t) in PT_set:
        meta = bidder_metadata.get(p, {})
        if meta.get('class') == 'Emitter': continue
        max_a = current_front_max.get((p, t), -1)
        bids_p = all_bids[p]
        discount = inflate2020_to_2025 * scenario.discount_rate(t - StartYear)
        kt_divisor = 1000.0 if meta.get('units') == 'kt' else 1.0

        is_forestry = meta.get('units') == 'mhectares' and p in forestry_meta
        if is_forestry:
            # Explicit reduced-cost formula (★): rc = obj + cooling_value - land_rent.
            # This is equivalent to obj + π_Vpt by LP duality, but robust to degeneracy.
            rotation = forestry_meta[p]['rotation_year']
            cooling_value = sum((SMDAMAGE.constraints[f"Capt({s})"].pi or 0.0) * (-sparse_Wpt.get((p, float(s - t)), 0.0))
                for s in ConstraintPeriods if s >= t and (p, float(s - t)) in sparse_Wpt)
            land_rent = sum((SMDAMAGE.constraints[f"Forestry_Land_{t_prime}"].pi or 0.0)
                for t_prime in bid_periods if t <= t_prime <= t + rotation - 1)
            dual = cooling_value - land_rent
        else: dual = dual_pi.get((p, t), 0.0)

        for a in range(max_a + 1, len(bids_p)):
            if (a, p, t) in restricted_APT_set: continue
            next_coeff, _ = bids_p[a]
            next_reduced_cost = next_coeff * discount / kt_divisor + dual
            if next_reduced_cost > 0.0:
                restricted_APT_set.add((a, p, t))
                expanded = True
                added_cols += 1
            else:
                for extra_a in range(a, min(a + 2, len(bids_p))):
                    restricted_APT_set.add((extra_a, p, t))
                    added_cols += 1
                break

NOTES ON THE REPLACEMENT CODE
------------------------------
1. `forestry_meta` is already available in Solve_SMDAMAGE (used for the Forestry_Land constraints in step 3.2).

2. `ConstraintPeriods` is already defined in Solve_SMDAMAGE.

3. `sparse_Wpt` is used instead of Wpt_dict to stay consistent with the rest of the function and avoid zero-valued terms.

4. `Capt(s).pi` is correct for BOTH revenue-neutral (where Capt bounds taxedTemperatureChange[s] ≤ 0) and non-revenue-neutral
   (where Capt bounds temperatureChange[s] ≤ -initial_temp) because in both cases the KKT identity ω_s = Capt(s).pi holds.

5. For non-forestry removers (Agriculture, Seaweed, CH4 abatement),  the Vpt dual already equals the cooling value with no land term,
   so the existing `dual_pi` path is unchanged.
